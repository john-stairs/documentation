# Introduction

This asset contains multiple RPG controllers for MMO or Action RPGs. It is greatly inspired by famous MMO and ARPG games, like World of Warcraft or Zelda BotW.

It is developed in Unity and can be bought from their Asset Store: [RPG Character Controllers](https://johnstairs.com/rpg-character-controllers/buy.html) (affiliate link).

!!! tip
    If you only want the camera logic, I also offer the modular [RPG Camera](../rpg-camera/introduction.md) as a separate asset. It can be seamlessly upgraded to the RPG Character Controllers asset anytime.
